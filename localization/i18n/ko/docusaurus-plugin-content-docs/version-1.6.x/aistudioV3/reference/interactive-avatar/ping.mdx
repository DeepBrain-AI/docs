# Session Keep-Alive

Chat을 보내거나 응답을 생성하지 않고 session activity를 갱신합니다. Client는 연결되어 있지만 사용자가 idle 상태일 때, 3분 inactivity timer로 session이 중지되지 않도록 사용합니다.

이 API는 Account `max_session_duration`을 연장하지 않습니다. 해당 limit은 계속 적용됩니다.

<span className="http-method http-method--post">POST</span>/api/v2/sessions/\{sessionId\}/ping

## Headers

| 헤더          | 값                       |
| :------------ | :----------------------- |
| Authorization | Bearer \{session_token\} |

Request body는 필요 없습니다.

## 예시

<Tabs>
<TabItem value="curl" label="cURL">

```bash
curl https://ai-streamer.deepbrain.io/api/v2/sessions/${SESSION_ID}/ping \
-H "Authorization: Bearer ${SESSION_TOKEN}" \
-X POST
```

</TabItem>
<TabItem value="js" label="Node.js">

```js
import axios from "axios";
const sessionId = "${SESSION_ID}";
const sessionToken = "${SESSION_TOKEN}";

axios
  .post(
    `https://ai-streamer.deepbrain.io/api/v2/sessions/${sessionId}/ping`,
    null,
    {
      headers: {
        Authorization: `Bearer ${sessionToken}`,
      },
    },
  )
  .then((res) => {
    console.log(res.data);
  })
  .catch((error) => {
    console.error(error);
  });
```

</TabItem>
<TabItem value="py" label="Python">

```py
import requests

session_id = '${SESSION_ID}'
session_token = '${SESSION_TOKEN}'
url = f'https://ai-streamer.deepbrain.io/api/v2/sessions/{session_id}/ping'

headers = {
    'Authorization': f'Bearer {session_token}'
}

response = requests.post(url, headers=headers)
print(response.json())
```

</TabItem>

## 성공 (`code: 1000`)

```json
{
  "code": 1000,
  "data": {
    "session_id": "${SESSION_ID}",
    "idle_timeout_sec": 180,
    "next_ping_recommended_sec": 120
  },
  "message": "Session activity refreshed"
}
```

Session을 유지해야 하는 동안 `next_ping_recommended_sec`초 간격으로 호출하세요. Auth와 error 동작은 Talk와 같습니다(`4030`, `4040`, `4090`). LiveKit room이 이미 사라진 경우 `SESSION_ROOM_NOT_FOUND`는 `5000`으로 mapping됩니다.
